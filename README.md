# Projets académiques – Sorbonne Université

Ce dépôt regroupe l’ensemble des projets réalisés dans le cadre de ma licence d’informatique à Sorbonne Université (L2–L3), couvrant différents domaines fondamentaux de l’informatique.

## Domaines abordés

### Systèmes, réseaux et infrastructures
- Systèmes d’exploitation
- Administration système (bases)
- Notions de réseau et d’architecture logicielle

### Développement et ingénierie logicielle
- Programmation orientée objet (Java)
- Programmation système (C avancé)
- Structures de données
- Algorithmique

### Sécurité et théorie
- Cryptologie (bases)
- Mathématiques discrètes

### Données et web
- Sciences des données
- Technologies du web

### Autres domaines
- Intelligence artificielle (initiation)
- Projets de développement et jeux

## Objectif
Ce dépôt regroupe des projets académiques permettant d’explorer les différents domaines de l’informatique. Cette base m’a progressivement orienté vers les systèmes, les réseaux et la cybersécurité, que je développe aujourd’hui en master.
